## The bar
Every image is a finished, textured, lit build. None of them has bare flat ground, straight unbroken walls or a
building sitting alone in a field. Each has a clear focal point, a path leading to it, and dense small detail
next to big shapes. That's the standard; see [[Build Style Guide]].
