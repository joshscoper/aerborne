## Native Paper integration

Final jar passed **230 checks** on Paper 26.2 build 121 in the existing disposable
`runtime/metallurgy-probe-20261022-222507` fixture. It binds only to loopback and has
the external game API and GeoIP disabled. `runtime/metrics-native-final.log` records
the fresh pass and clean shutdown. Metrics-specific checks verify:

1. Tracking starts with the staff panel disabled.
2. Real progression/economy service wrappers and callback queues collect commits.
3. Retried XP/credits, refused debits and separately recorded transfers are correct.
4. Production PanelData publishes aggregate metrics without the private visit/session indexes.
5. Background atomic persistence restores the expected totals through the real ledger.

The combined fixture also reruns metallurgy, stats/XP, drop consolidation, hostile
spawn and encounter behavior checks. It uses controlled actors and actual Paper
services/entities; it does not simulate real Minecraft client logins or a live population.
