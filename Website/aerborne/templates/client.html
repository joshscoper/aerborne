Three steps

How to install

  1. Install Fabric for Minecraft 26.2. Use the Fabric installer, or a launcher such as Modrinth App or Prism, and make a 26.2 Fabric profile (Fabric Loader 0.20.1 or newer).
  2. Add the mods. Put Fabric API (0.161.0+26.2 or newer) and the Aerborne client jar in that profile's mods folder. Sodium works alongside it and is recommended.
  3. Play. Launch the profile; play.aerborne.net is already in your server list. Press B for the Aerborne menu, H to show or hide the HUD and J for waypoints.

Updating? Replace the old jar rather than keeping both. Java 25 is required; current launchers include it.

Only download the client from this page. To check your copy, compare its SHA-256 with the one shown above.
