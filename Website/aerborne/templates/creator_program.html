How creator codes and earnings work

Acceptance unlocks code requests; a request is reviewed before the code becomes active. You must have an eligible Tebex Wallet in your own name or business and provide its wallet reference privately. Never send us bank credentials or a wallet password.

The program share is 25% on qualifying purchases attributed to your active code. Tebex calculates the actual allocation, fees, taxes, refunds and payout eligibility. A dashboard estimate is not a wallet balance or a promise of a payout date. Tebex manages settlement and withdrawals.

Code users receive a 10% discount where the configured code is eligible. Discount stacking, excluded products and gift-card restrictions are determined at checkout. For subscriptions, Tebex applies code revenue share and discount to the initial payment only.

Do not mislead buyers, impersonate others, exploit codes or encourage rule-breaking. Aerborne can suspend membership and code access for misuse. Suspension does not remove statutory rights or change Tebex's treatment of already completed payments. Program changes will be communicated before applying to future purchases.
