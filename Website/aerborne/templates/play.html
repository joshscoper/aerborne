Java Edition

  1. Open Minecraft: Java Edition

    Launch version {{ site.MINECRAFT_VERSIONS }} from the Minecraft Launcher. You don't need mods or a resource pack.

  2. Add the server

    {% if server_address %}

    Go to Multiplayer, choose Add Server, and paste {{ server_address }} as the server address.

    {% else %}

    The public address isn't out yet. It'll appear here and on Discord.

  3. Create your island

    Join, then type /island create. You'll land on your own floating island.

  4. Follow the quickstart

    Type /quickstart for a short route through your first session. The Getting Started guide covers the same path with pictures.

Can't connect?

"Outdated client" or "Outdated server"
Switch to Minecraft {{ site.MINECRAFT_VERSIONS }} in the launcher's Installations tab.
"You are not white-listed on this server"
{{ site.SITE_NAME }} is in private testing. Staff add testers to the whitelist.
"Can't connect to server" or a timeout
Check the address for typos, then check server status. If it's offline, it may be restarting.
