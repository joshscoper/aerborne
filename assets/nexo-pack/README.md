# NerdSMP Nexo source pack

This directory is the checked-in source pack imported by Nexo. The local runner mirrors it into `plugins/Nexo/pack/external_packs/NerdSMP`.

The current ItemModel files deliberately point at vanilla models so every signature item has a valid fallback before commissioned textures and models arrive. Replace the referenced models with licensed NerdSMP assets without changing the stable `nerdsmp:<item-id>` ItemModel keys used by the gameplay plugin.
